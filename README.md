# AudioGenie3

AudioGenie3 is a COM DLL for reading and writing audio file metadata
(ID3v1, ID3v2, APE, Vorbis comments, WMA, MP4, WAV and more).

- API documentation: generate with `doxygen Doxyfile` (output in `docs/`)
- Tests: see `tests/README.md`
- Sample projects: `VBasic/`
