store a picture from a file in the tag

There may be more than one picture frame in each tag, but only one with the same content descriptor.

Since
2.0.2.0
Parameters
FileNamename of the picture file
Descriptiona description of the picture
PictureTypetype from 0 to 20, see Picture types
asLinkshows how the picture will be stored
  • -1 = only a link to the image will be stored
  • 0 = the image data will be stored
    Returns
