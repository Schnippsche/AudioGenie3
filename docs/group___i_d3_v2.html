Read and write ID3v2 tags (v2.2, v2.3, v2.4): text, URL, comment, lyrics, pictures, chapters and further frames.

◆ ID3V2GetTextFrameW()

BSTR ID3V2GetTextFrameW ( u32 FrameID)

get the text entry of an ID3v2 frame

The frame must be a text frame (T000 to TZZZ, except TXXX), also one that this library does not know. An ID3v2.4 text frame can contain several strings; this function returns the first one. All strings are kept when the tag is saved again (in an ID3v2.2 or ID3v2.3 tag they are separated by a slash).

Since
2.0.1.0
Parameters
FrameIDthe frame id
Returns
frame text, empty if the frame does not exist or is not a text frame

short ID3V2SetFormatAndEncodingW ( short format,
short encoding )

set the format and text encoding of the ID3v2 tag

The encoding applies to all text frames when the tag is saved. Text that ISO-8859-1 cannot represent is not replaced by question marks: such a frame is stored as UTF-16 with BOM instead.

Since
2.0.1.0
Parameters

encoding0= ISO-8859-1 1=UTF-16 with BOM 2=UTF-16BE without BOM 3=UTF-8
Returns
normally -1, 0 on error
