Funktionen der Gruppe APE:

Funktionen:
FunktionsnameBeschreibung
APEExistsW zeigt an, ob ein APE-Tag existiert
APEGetAlbumW liefert das Album
APEGetArtistW liefert den Interpreten
APEGetCommentW liefert den Kommentar
APEGetCopyrightW liefert das Copyright
APEGetGenreW liefert das Genre
APEGetItemKeysW liefert alle Feldnamen durch Kommas getrennt, die Textwerte beinhalten
APEGetSizeW liefert die Grösse des APE-Tags in Bytes
APEGetTitleW liefert den Titel
APEGetTrackW liefert den Track
APEGetUserItemW liefert ein benutzerdefiniertes Feld
APEGetVersionW liefert die Version des APE-Tags
APEGetYearW liefert das Jahr
APERemoveTagFromFileW entfernt den APE-Tag von einer Datei. Achtung: Die Löschung wird sofort durchgeführt!
APERemoveTagW entfernt den APE-Tag von der zuletzt analysierten Datei. Achtung: Die Löschung wird sofort durchgeführt!
APESaveChangesToFileW speichert den APE-Tag in eine Datei
APESaveChangesW speichert den APE-Tag in die zuletzt analysierte Datei
APESetAlbumW setzt das Album
APESetArtistW setzt den Interpreten
APESetCommentW setzt den Kommentar
APESetCopyrightW setzt das Copyright
APESetGenreW setzt das Genre
APESetTitleW setzt den Titel
APESetTrackW setzt den Track
APESetUserItemW setzt ein benutzerdefiniertes Feld
APESetYearW setzt das Jahr
