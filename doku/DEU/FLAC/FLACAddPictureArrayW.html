Funktion: FLACAddPictureArrayW

aus Gruppe FLAC , released seit Version 2.0.2.0

Int16 FLACAddPictureArrayW(Pointer Zeiger, UInt32 Length, LPCWSTR Beschreibung, Int16 PictureTyp)

Beschreibung:
überträgt ein Bild aus einem Byte-Array in einen FLAC-Tag

Es kann mehr als einen Eintrag geben, aber nur einen mit der gleichen Sprache und Inhaltsbeschreibung.
Parameter:
DatentypBezeichnerBeschreibung
PointerZeigerauf ein Byte Array mit den Daten des Bildes
UInt32Lengthdie Grösse des Arrays in Bytes
LPCWSTRBeschreibungKommentar zu dem Bild
Int16PictureTypTyp des Bildes von 0 bis 20
00 = Other
01 = 32*32 pixels file icon
02 = Other file icon
03 = Cover front
04 = Cover back
05 = Leaflet page
06 = Media ( label side of CD )
07 = Lead artist/solist
08 = Artist/Performer
09 = Conductor
10 = Band/Orchestra
11 = Composer
12 = Lyricist/text writer
13 = Recording Location
14 = During recording
15 = During performance
16 = Movie/video screen capture
17 = A bright coloured fish
18 = Illustration
19 = Band/artist logotype
20 = Publisher/Studio logotype
Rückgabewert:
Int16 -1 falls frame ersetzt wurde, 0 falls neuer Eintrag erfolgte
Beispiel:

result = AudioGenie.FLACAddPictureArrayW(Zeiger, Length, Beschreibung, PictureTyp)
