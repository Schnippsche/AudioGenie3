Funktion: ID3V2AddEncryptionW

aus Gruppe ID3V2 , released seit Version 2.0.1.0

Int16 ID3V2AddEncryptionW(Pointer Zeiger, UInt32 maxLen, LPCWSTR Identifikator, Int16 Symbol)

Beschreibung:
ENCR fügt einen Enryption Frame hinzu
Es kann mehr als einen 'ENCR' Eintrag geben, aber nur einen mit dem gleichen Symbol und Identifikator.
Parameter:
DatentypBezeichnerBeschreibung
PointerZeigerauf ein Byte Array mit den Verschlüsselungsdaten
UInt32maxLenmaximale Grösse des Arrays in Bytes
LPCWSTRIdentifikatordes Besitzers
Int16SymbolMethode Symbol
Rückgabewert:
Int16 -1 falls frame ersetzt wurde, 0 falls neuer Eintrag erfolgte
Beispiel:

result = AudioGenie.ID3V2AddEncryptionW(Zeiger, maxLen, Identifikator, Symbol)
