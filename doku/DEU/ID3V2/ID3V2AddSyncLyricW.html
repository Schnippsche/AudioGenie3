Funktion: ID3V2AddSyncLyricW

aus Gruppe ID3V2 , released seit Version 2.0.1.0

Int16 ID3V2AddSyncLyricW(LPCWSTR language, LPCWSTR description, LPCWSTR text, Int16 contenttype, Int16 timestampformat)

Beschreibung:
"SYLT" setzt oder ersetzt einen synchronen Liedtext-Eintrag
Es kann mehr als einen 'SYLT' Eintrag geben, aber keine zwei mit der gleichen Sprache und Beschreibung.
Parameter:
DatentypBezeichnerBeschreibung
LPCWSTRlanguagedas Sprachkürzel des Eintrages ( genau 3 Bytes ) z.B. ENG
LPCWSTRdescriptiondie Beschreibung des Eintrages
LPCWSTRtextdie eigentlichen Eintraege durch Zeilenumbruch (CRLF) getrennt. Folgendes Format muss verwendet werden:

[xxxxxxxx]eintrag1
[xxxxxxxx]eintrag2 usw

xxxxxxxx = absolute Zeitangabe 8 stellig
eintrag = beliebiger Texteintrag

Beispiel:
[00000010]Strang
[00000020]ers
[00000080]in
Int16contenttypelegt den Inhaltstyp fest. Folgende Werte sind möglich:

0 = Sonstiges
1 = Songtexte
2 = Textumschreibungen
3 = Bewegungen
4 = Ereignisse
5 = Akkorde
6 = Belangloses
7 = URLs zu Webseiten
8 = URLs zu Bildern
Int16timestampformatgibt an, wie die Zeitangaben erfolgen

1 = Zeitangaben in MPEG frames
2 = Zeitangaben in millisekunden
Rückgabewert:
Int16 -1 falls frame ersetzt wurde, 0 falls neuer Eintrag erfolgte
Beispiel:

result = AudioGenie.ID3V2AddSyncLyricW(language, description, text, contenttype, timestampformat)
