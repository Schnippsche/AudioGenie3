Funktionen der Gruppe MP4:

Funktionen:
FunktionsnameBeschreibung
MP4AddPictureArrayW überträgt ein Bild aus einem Byte-Array in den Tag
MP4AddPictureFileW überträgt ein Bild aus einer Datei in einen Tag
MP4DeleteEntriesW löscht alle benutzerdefinierten Einträge wie Titel, Bilder etc.
MP4DeletePictureW entfernt ein Bild
MP4DeletePicturesW entfernt alle Bilder
MP4GetAllFrameIDsW liefert eine kommagetrennte Liste aller vorkommenden eindeutigen Frame IDs
MP4GetGenreW liefert das Genre
MP4GetPictureArrayW überträgt ein Bild aus dem frame in ein Byte-Array
MP4GetPictureCountW liefert die Anzahl der Bilder
MP4GetPictureFileW überträgt ein Bild mit einem bestimmten Index in eine Datei
MP4GetPictureMimeW liefert den Mimetyp eines Bildes, z.B. "jpg" oder "png"
MP4GetPictureSizeW liefert die Grösse eines Bildes in Bytes
MP4GetTextFrameW liefert den Text eines ILST mp4 Textframes
MP4GetTrackW liefert den Track
MP4GetVersionW liefert das Format / die Version
MP4GetiTuneFrameW liefert den Text eines mp4 iTune Textframes
MP4SaveChangesToFileW speichert Änderungen der mp4 Datei
MP4SaveChangesW speichert die MP4-Änderungen in die zuletzt analysierte Datei
MP4SetGenreW setzt das Genre
MP4SetTextFrameW setzt den text eines mp4 ILST Textframes
MP4SetTrackW setzt den Track
MP4SetiTuneFrameW setzt den text eines mp4 iTune Textframes
