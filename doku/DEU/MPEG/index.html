Funktionen der Gruppe MPEG:

Funktionen:
FunktionsnameBeschreibung
MPEGGetEmphasisW liefert die Rauschunterdrückung
MPEGGetEncoderW liefert den Kodierer
MPEGGetFramePositionW liefert die Position des ersten gültigen Frames
MPEGGetFrameSizeW liefert die Frame-Grösse in Bytes
MPEGGetFramesW liefert die Anzahl der Frames
MPEGGetLayerW liefert den Layer
MPEGGetVersionW liefert die Version z.B. "MPEG 2.0"
MPEGIsCopyrightedW zeigt an, ob die Datei Copyright geschützt ist
MPEGIsOriginalW zeigt an, ob die Datei ein Original ist
MPEGIsPaddingW zeigt an, ob Auffüllen verwendet wird
MPEGIsPrivateW zeigt an, ob das Privat bit gesetzt ist
MPEGIsProtectedW zeigt an, ob das Protected bit gesetzt ist
MPEGIsVBRW zeigt an, ob variable Bitrate verwendet wird
MPEGSetCopyrightedW verändert das Copyright Bit einer MPEG-Datei
MPEGSetOriginalW verändert das Original Bit einer MPEG-Datei
MPEGSetPrivateW verändert das Private Bit einer MPEG-Datei
