Funktionen der Gruppe WAV:

Funktionen:
FunktionsnameBeschreibung
WAVGetBitsPerSampleW liefert die Bits pro Sample
WAVGetBlockAlignW liefert die Blockausrichtung
WAVGetBytesPerSecondW liefert die Anzahl der Bytes pro Sekunde
WAVGetCartChunkEntryW liefert einen wav cartchunk Eintrag
WAVGetChannelsW liefert die Anzahl der Kanäle
WAVGetDisplayTextW liefert den Text eines Display chunks
WAVGetFormatIDW liefert die Format-ID der Datei
WAVGetFormatW liefert das Format im Klartext
WAVGetHeaderSizeW liefert die Grösse des Headers in Byte
WAVGetInfoChunkIDsW liefert eine kommagetrennte Liste aller vorkommenden eindeutigen Info Chunk IDs
WAVGetTextFrameW liefert einen wav Text Frame (info chunk)
WAVSaveChangesToFileW speichert den WAV Tag in eine Datei
WAVSaveChangesW speichert den WAV-Tag in die zuletzt analysierte Datei
WAVSetCartChunkEntryW setzt oder ersetzt einen Wav CartChunk Eintrag
WAVSetDisplayTextW setzt den Text eines DISPLAY chunks
WAVSetTextFrameW setzt oder ersetzt einen Wav Text frame (info chunk)
