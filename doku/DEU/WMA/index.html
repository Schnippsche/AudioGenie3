Funktionen der Gruppe WMA:

Funktionen:
FunktionsnameBeschreibung
WMAGetPictureArrayW "WM/Picture" überträgt ein Bild aus dem Tag in ein Byte-Array
WMAAddPictureArrayW überträgt ein Bild aus einem Byte-Array in den Tag
WMAAddPictureFileW überträgt ein externes Bild in einen Tag
WMADeletePictureW entfernt ein Bild mit WM/Picture Tag
WMADeletePicturesW entfernt alle Bilder mit WM/Picture Tag
WMAGetPictureCountW liefert die Anzahl der Bilder
WMAGetPictureDescriptionW liefert die Beschreibung eines Bildes
WMAGetPictureFileW "WM/Picture" überträgt ein Bild aus dem Tag in eine Datei
WMAGetPictureMimeW liefert den Mimetyp eines Bildes
WMAGetPictureTypeW liefert den Bildtyp eines Bildes
WMAGetItemKeysW liefert alle Feldnamen durch Kommas getrennt
WMAGetPictureSizeW liefert die Grösse eines Bildes in Bytes
WMAGetUserItemW liefert ein benutzerdefiniertes Feld
WMAIsVBRW zeigt an, ob variable Bitrate verwendet wird
WMASaveChangesToFileW speichert die Änderungen im WMA-Tag in eine Datei
WMASaveChangesW speichert die Änderungen im WMA-Tag in die zuletzt analysierte Datei
WMASetUserItemW setzt ein benutzerdefiniertes Feld
