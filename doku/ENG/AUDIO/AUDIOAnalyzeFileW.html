Method: AUDIOAnalyzeFileW

from Group AUDIO , released since Version 2.0.1.0

Int16 AUDIOAnalyzeFileW(LPCWSTR filename)

Description:
read an audio-file and all known tags
the tags will be reading in this way:
files with format WMA, MP4, FLAC and OGG uses their own fields. All other formats have this rules:
at first id3v2 tag, if not exist then ape tag, if not exist then id3v1 tag and at least lyrics tag.
Parameter:
DatatypeIdentifierDescription
LPCWSTRfilenamename of the file
Return Value:
Int16 return value from 0 to 10 with the following meaning:

ValueDescription
0unknown Format
1MP3
2WMA
3MONKEY
4FLAC
5WAV
6OGG VORBIS
7MPP
8AAC
9MP4/M4A
10TTA
11wavpack
Example:

result = AudioGenie.AUDIOAnalyzeFileW(filename)
