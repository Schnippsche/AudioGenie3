Methods of Group ID3V1:

Methods:
Method NameDescription
ID3V1ExistsW shows -1, if ID3v1 tag exists
ID3V1GetAlbumW get the album
ID3V1GetArtistW get the artist
ID3V1GetCommentW get the comment
ID3V1GetGenreIDW get the genre number
ID3V1GetGenreItemW get a genre for a specific number ( 0 to ID3V1GetGenresW - 1 )
ID3V1GetGenreW get the genre
ID3V1GetGenresW get the number of supported genres
ID3V1GetTitleW get the title
ID3V1GetTrackW get the track
ID3V1GetVersionW get the version of the id3v1 tag
ID3V1GetYearW get the year
ID3V1RemoveTagFromFileW remove the ID3v1-Tag from a File. Attention: This function removes the tag immediately!
ID3V1RemoveTagW remove the ID3v1-Tag from the last analyzed File. Attention: This function removes the tag immediately!
ID3V1SaveChangesToFileW stores the ID3v1 tag into a file
ID3V1SaveChangesW stores the ID3v1 tag into the last analyzed file
ID3V1SetAlbumW set the album
ID3V1SetArtistW set the artist
ID3V1SetCommentW set the comment
ID3V1SetGenreIDW set the genre number
ID3V1SetGenreW set the genre
ID3V1SetTitleW set the title
ID3V1SetTrackW set the track
