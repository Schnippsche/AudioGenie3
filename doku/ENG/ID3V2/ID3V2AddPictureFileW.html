Method: ID3V2AddPictureFileW

from Group ID3V2 , released since Version 2.0.1.0

Int16 ID3V2AddPictureFileW(LPCWSTR Filename, LPCWSTR description, Int16 picture, Int16 asLink)

Description:
"APIC" store a picture from a file in the tag
There may be more than one 'APIC' frame in each tag, but only one with the same content descriptor.
Parameter:
DatatypeIdentifierDescription
LPCWSTRFilenamename of the picture file
LPCWSTRdescriptiona description of the picture
Int16picturetype from 0 to 20
00 = Other
01 = 32*32 pixels file icon
02 = Other file icon
03 = Cover front
04 = Cover back
05 = Leaflet page
06 = Media ( label side of CD )
07 = Lead artist/solist
08 = Artist/Performer
09 = Conductor
10 = Band/Orchestra
11 = Composer
12 = Lyricist/text writer
13 = Recording Location
14 = During recording
15 = During performance
16 = Movie/video screen capture
17 = A bright coloured fish
18 = Illustration
19 = Band/artist logotype
20 = Publisher/Studio logotype
Int16asLinkshows how the picture will be stored

-1 = only a link to the image will be stored
0 = the image data will be stored
Return Value:
Int16 normally -1, 0 on error
Example:

result = AudioGenie.ID3V2AddPictureFileW(Filename, description, picture, asLink)
