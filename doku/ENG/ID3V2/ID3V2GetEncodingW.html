Method: ID3V2GetEncodingW

from Group ID3V2 , released since Version 2.0.1.0

Int16 ID3V2GetEncodingW(UInt32 FrameID)

Description:
get the encoding of the selected frame
Parameter:
DatatypeIdentifierDescription
UInt32FrameIDthe ID of the frame
Return Value:
Int16 Encoding -1= FrameID not found 0= ISO-8859-1 1=UTF-16 with BOM 2=UTF-16 without BOM 3=UTF-8
Example:

result = AudioGenie.ID3V2GetEncodingW(FrameID)
