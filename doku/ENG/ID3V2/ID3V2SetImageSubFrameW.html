Method: ID3V2SetImageSubFrameW

from Group ID3V2 , released since Version 2.0.1.0

Int16 ID3V2SetImageSubFrameW(Pointer pointer, UInt32 maxLen, LPCWSTR ID, LPCWSTR Description, Int16 PictureType)

Description:
set a picture frame, will be replaced if exists
Parameter:
DatatypeIdentifierDescription
Pointerpointerto a byte array with picture data
UInt32maxLenmaximum size of the array in bytes
LPCWSTRIDthe ID of the parent frame
LPCWSTRDescriptionthe description of the image
Int16PictureTypetype from 0 to 20
00 = Other
01 = 32*32 pixels file icon
02 = Other file icon
03 = Cover front
04 = Cover back
05 = Leaflet page
06 = Media ( label side of CD )
07 = Lead artist/solist
08 = Artist/Performer
09 = Conductor
10 = Band/Orchestra
11 = Composer
12 = Lyricist/text writer
13 = Recording Location
14 = During recording
15 = During performance
16 = Movie/video screen capture
17 = A bright coloured fish
18 = Illustration
19 = Band/artist logotype
20 = Publisher/Studio logotype
Return Value:
Int16 normally -1, 0 on error
Example:

result = AudioGenie.ID3V2SetImageSubFrameW(pointer, maxLen, ID, Description, PictureType)
