Methods of Group MPEG:

Methods:
Method NameDescription
MPEGGetEmphasisW get the emphasis
MPEGGetEncoderW get the encoder
MPEGGetFramePositionW get the position of the first valid frame
MPEGGetFrameSizeW get the frame size in bytes
MPEGGetFramesW get the number of Frames
MPEGGetLayerW get the layer
MPEGGetVersionW get the mpeg version e.g. "MPEG 2.0"
MPEGIsCopyrightedW shows the copyright state of a file
MPEGIsOriginalW shows the original state of the file
MPEGIsPaddingW shows the state of padding
MPEGIsPrivateW shows the state of the private bit
MPEGIsProtectedW shows the state of the protected bit
MPEGIsVBRW shows -1, if it is variable bitrate
MPEGSetCopyrightedW modify the State of the Copyright Bit
MPEGSetOriginalW modify the State of the Original Bit
MPEGSetPrivateW modify the State of the Private Bit
