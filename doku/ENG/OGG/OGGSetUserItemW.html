Method: OGGSetUserItemW

from Group OGG , released since Version 2.0.1.0

OGGSetUserItemW(LPCWSTR myKey, LPCWSTR myValue)

Description:
set a user defined field
use the method OGGGetItemKeys for a list of all existing keys.
Parameter:
DatatypeIdentifierDescription
LPCWSTRmyKeythe key you want to set
LPCWSTRmyValuenew value for the key, empty string remove this item
