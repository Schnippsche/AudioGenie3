Groups

The methods are structured by the audio formats. In the Group "Audio" are properties, who applies to all formats ( e.g. the duration or file length ), all others are format specific.

AAC  APE  AUDIO  FLAC  ID3V1  ID3V2  LYRICS  MONKEY  MP4  MPEG  MPP  OGG  UNIVERSAL  WAV  WMA  

Data types

The properties and methods uses the following data types:
DatatypeDescription
Int16a 16-bit signed integer
Int32a 32-bit signed integer
UInt32a 32-bit unsigned integer
Floata 32-bit floating value
BSTRa basic string starting with 4 bytes length info followed by a sequence of 16bit Unicode chars (UTF-16)
LPCWSTRa pointer to a sequence of 16bit Unicode chars (UTF-16), terminated with $0 $0
Pointera 32bit pointer to the address of a byte array
