AudioGenie3

AudioGenie3 is a library for analyzing and tagging audio files. All functions are exported from the DLL with the __stdcall calling convention and a W suffix for the Unicode variants.

Usage: call AUDIOAnalyzeFileW() first; all other functions then work on the analyzed file. The library is single-threaded by design and keeps its state in global objects.

The functions are grouped by tag or format, see the Topics page.
